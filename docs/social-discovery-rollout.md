2. Generate the transaction below from the canonical checkout and review it. Execute it in one request against the approved project. The migration history entries and schema changes commit together. The old three-argument mutation is replaced, so coordinate use of the matching local app with activation.

   ```powershell
   $identityVersions = @(
     @{ Version = '20261111104309'; Name = 'identity_following' }
     @{ Version = '20261111104334'; Name = 'social_discovery' }
   )
   $identityDelimiter = '$modvault_identity_rollout$'
   $identityTransaction = @(
     'begin;'
     "set local lock_timeout = '5s';"
     "set local statement_timeout = '60s';"
     'lock table supabase_migrations.schema_migrations in share row exclusive mode;'
     foreach ($item in $identityVersions) {
       $file = "supabase/migrations/$($item.Version)_$($item.Name).sql"
       $sql = Get-Content -Raw -LiteralPath $file
       if ($sql.Contains($identityDelimiter)) { throw 'Migration contains the transaction delimiter' }
       "insert into supabase_migrations.schema_migrations(version,name,statements) values ('$($item.Version)','$($item.Name)',array["
       ($identityDelimiter + $sql + $identityDelimiter + ']);')
       $sql
     }
     'commit;'
   ) -join "`n"
   $identityTransaction
   ```
